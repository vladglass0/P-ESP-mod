# P-ESP-mod

Клиентский мод для Minecraft Java 1.21.8 на Fabric. Подсвечивает контуры других игроков, загруженных у клиента, сквозь блоки.

## Установка

Установите Java 21 и Fabric Loader 0.17.2 или новее для Minecraft 1.21.8. Поместите JAR мода и Fabric API для 1.21.8 в папку `mods` профиля. В игре нажмите **O**, чтобы переключить подсветку. Клавишу можно переназначить в настройках управления.

## Сборка на Linux

Используйте JDK 21 и Gradle 8.14.3. В корне репозитория выполните `gradle build`. Готовый файл появится в `build/libs/player-esp-1.0.0.jar`.

## Проверка и релиз

GitHub Actions запускает `gradle build` при пуше в ветку и при обновлении pull request. После успешной сборки тега с префиксом `v` workflow публикует GitHub Release с JAR.

Перед релизом установите нужную версию в `build.gradle` и отправьте тег для соответствующего коммита. Например, для версии 1.0.0 выполните:

```bash
git tag v1.0.0
git push origin v1.0.0
```
